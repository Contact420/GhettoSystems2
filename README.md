# GhettoSystems2

Android home-lab control app — **version 2.4.9** (versionCode 25).

Package: `com.ghettosystems.v2`

## Features
- Device dashboard (garage door, compressors, sensors)
- PSI cut-out control (tap pressure → slider 40–90 → Set)
- Account settings, biometrics, device config
- Paired with GhettoSystems cloud/API on LAN

## Build
Open in Android Studio, sync Gradle, Run.

```
./gradlew :app:assembleDebug
```
